# Changelog

## 0.2.0

- Added an IFTO-HOME-inspired First Look overview while reimplementing the UI in the existing Markdown + DataviewJS dashboard.
- Added top section navigation, today/project/task/recent widgets, and a lightweight input focus guard for embedded controls.
- Upgraded common folder shortcuts with note/project counts and latest update timestamps.
- Upgraded research project management with board metrics, status/phase/priority filters, direct open buttons, and more visual project modules.
- Kept the dashboard scoped to `cssclasses: home-research-os` and retained editable Markdown project notes as the source of truth.

## 0.1.0

- Initial plugin packaging for Yian Research OS.
- Added commands to install, refresh, and open the research home.
- Added generated templates for `HOME.md`, quick memos, reminders, daily essays, and scoped CSS.
- Added settings for vault paths, backup behavior, CSS snippet enabling, and DataviewJS setup.
